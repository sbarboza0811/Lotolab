# LotoLab — publicação fácil no GitHub Pages

Este pacote tem o site completo em **apenas um `index.html`**, sem banco de dados.

1. Repositório: https://github.com/sbarboza0811/Lotolab (já criado).
2. O arquivo `index.html` já está publicado na raiz da branch `main`.
3. Vá em **Settings > Pages > Build and deployment**, escolha **Deploy from a branch**, branch **main**, pasta **/(root)** e clique em **Save**.
4. Abra a URL que o GitHub mostrar em Pages (em geral `https://sbarboza0811.github.io/Lotolab/`).

Os resultados são carregados de fontes externas, sem precisar de banco ou chave de API. As frequências indicam apenas o passado; nenhuma técnica prevê sorteios independentes.

Fontes: Caixa, compilada por https://loteria.superfacil.site/dados-abertos/ (CC BY 4.0); Super Sete: https://github.com/maickon/free-apiloterias e https://github.com/guilhermeasn/loteria.json; regras oficiais https://loterias.caixa.gov.br/.
